# Magisk 和 Bootloader 检测

[![Downloads](https://img.shields.io/github/downloads/lalakii/lalaki-root-and-bootloader-checker/total)](https://github.com/lalakii/lalaki-root-and-bootloader-checker/releases)

几行简单的代码，检测你的 Magisk 和 Bootloader 锁伪装是否成功。

## 为什么要伪装无 Root 和 Bootloader上锁状态? 不伪装或伪装失败会发生什么?

+ 微信直接风控, 提示账号异常, 甚至直接封号
+ 大部分金融类App直接无法运行
+ 指纹支付 / 面容支付功能失效
